A trained classifier that flags likely oil-spill imagery.

MARIS runs a MobileNetV2 model, fine-tuned on labeled satellite/coastal image patches, to predict whether a given image shows an oil slick at sea. Upload an image on the Analyze page to see a live prediction.

Scope, honestly stated: two things are running here. The classifier below works on any uploaded image (Analyze page). Separately, the Case study page shows a real Sentinel-1 SAR analysis + AIS correlation done for one historical incident, the MV Wakashio spill (Mauritius, Aug 2020) — that pipeline is not yet wired to run automatically on a new arbitrary image.

What's real vs. what's next

  • Built: image classifier (Overview/Analyze), trained + evaluated on real held-out data
  • Built: SAR candidate detection + AIS proximity/time correlation for the Wakashio case study — see Case study page
  • Not yet: running the SAR + AIS pipeline automatically on a newly uploaded image — it currently runs on one prepared historical scene
  • Not yet: drift / backward origin-region modeling
  • Not yet: pixel-level segmentation (classifier judges whole images, not sub-regions)
